# Internship Project: Network Monitoring and Security Log Analysis with ELK Stack and pfSense

## Project Overview

This project was carried out as part of an internship and focuses on network monitoring, centralized log management, and security event analysis using the Elastic Stack and network security tools.

## Project Objectives

- Centralize and analyze security and infrastructure logs.
- Visualize monitoring data and security events through Kibana.
- Collect and analyze firewall logs from pfSense.
- Explore network intrusion detection using Suricata IDS/IPS.
- Monitor system performance and network activity.

## Technologies Used

- Elasticsearch 8.19.18
- Logstash 8.19.18
- Kibana 8.19.18
- pfSense
- Suricata IDS/IPS
- Metricbeat
- Packetbeat
- Ubuntu Server
- VMware
