# Cybersecurity Lab: ELK Stack, pfSense and Suricata

## Project Overview

A virtual cybersecurity lab focused on centralized logging,
network monitoring, firewall visibility and intrusion detection.

## Objectives

- Centralize and analyze security logs.
- Visualize events through Kibana.
- Document firewall monitoring with pfSense.
- Explore network intrusion detection with Suricata.
- Monitor systems and network activity.

## Technologies

- Elasticsearch 8.19.18
- Logstash 8.19.18
- Kibana 8.19.18
- pfSense
- Suricata IDS/IPS
- Metricbeat and Packetbeat
- Ubuntu Server
- VMware / VirtualBox
